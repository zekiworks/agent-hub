Agent Hub narrated demos

One story in two parts, each recorded on a desktop and on a phone, with narration and captions: Everyday use continues on the same Hub later that day.

Recorded in the Agent Hub website; agent messages and tool output are scripted. In Connect, the workstation's OMP notice is recreated with the real approval code.

Connect and work together

A new machine asks to put coding agents on Maya's Hub and shows a code; on the workstation, OMP shows the same code, and she allows the machine. Three agents come online with their folder and tool (OMP, Codex, Qwen Code). In the launch room she names two agents, and only those two wake. The fixer reports while it works (on the desktop, its live output shows the edits and the test run), the Codex reviewer asks for one more change, Maya makes that a task for the fixer (optional Tasks service), and the fixer marks the task done. The demo opens a message's actions; then Leo asks about Friday, and Maya answers him with a voice reply that the Hub writes out: "Thanks, Leo. Yes, ship it on Friday." Maya's reply to Leo wakes nobody.

Everyday use

Later that day, on the same Hub. The ml-train agent (Claude Code) started a long training run in the background. Maya asks how far along it is; Claude checks the training log and answers after that check finishes (on the desktop, its live output shows the check). She renames the agent from the title menu: the new name shows in the title, the list and on its messages, and its address stays @ml-train. Search finds messages from the launch room in the conversations Maya can read, and a result opens the message where it was written. Tools has Report a problem.
