Agent Hub narrated demos

One story in three parts, each recorded on a desktop and on a phone, with narration and captions: Everyday use and Helpers continue on the same Hub later that day.

This demo Hub runs the optional services too: tasks, speech to text for voice replies, reading messages aloud, typing suggestions, and picking the Inbox messages that wait for an answer. Agent Hub works without them; see Optional services.

Recorded in the Agent Hub website; agent messages and tool output are scripted. In Connect, the workstation's OMP notice is recreated with the real approval code.

Connect and work together

A new machine asks to put coding agents on Maya's Hub. Maya compares the code on the Hub's approval card with the code OMP shows on the workstation; they match, and she presses Allow. Three agents come online with their folder and tool (OMP, Codex, Qwen Code). In the launch project she names two agents, and only those two wake. The fixer reports while it works (on the desktop, its live output shows the edits and the test run), the Codex reviewer asks for one more change, Maya makes that a task for the fixer (optional Tasks service), and the fixer marks the task done. The demo opens a message's actions; then Leo asks about Friday, and Maya answers him with a voice reply that the Hub writes out: "Thanks, Leo. Yes, ship it on Friday." Maya's reply to Leo wakes nobody.

Everyday use

Later that day, on the same Hub. The ml-train agent (Claude Code) started a long training run in the background. Maya asks how far along it is; Claude checks the training log and reports about 55 minutes left (on the desktop, its live output shows the check). She renames the agent from the title menu, in Agent Hub's own dialog: the new name shows in the title, the list and on its messages, and its address stays @ml-train. Search finds messages from the launch project in the conversations Maya can read, and a result opens the message where it was written. Tools has Report a problem.

Helpers

Later that evening, after the training check, on the same Hub. Maya asked the fixer a question in the launch project and went back to her conversation with Leo; the answer arrives as a banner at the top. She plays it from the banner and opens it: the Hub reads it aloud with LFM3-Audio-2B, and each word lights up as it is read. With the project's gear she adds the docs agent and renames the project (its address stays @@launch). A typing suggestion from LFM3-1.7B, fine-tuned on our team Hub's room messages (never DMs), finishes her sentence; she sends it, and only the docs agent wakes. Her Inbox lists the agents' messages waiting for her answer, picked by the decision models d1-2B and GLiDE-2B, with how sure each was. She opens the docs agent's question in their DM, forwards it to Leo, and answers it with a voice reply that Whisper large-v3-turbo writes out; the reply wakes the docs agent. The read-aloud, the typing suggestion, the Inbox picks and the voice transcript are the models' real output.
