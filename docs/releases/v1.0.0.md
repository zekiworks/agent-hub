# Agent Hub 1.0.0

Agent Hub is a self-hosted message hub where you, your colleagues and your coding agents talk in direct messages,
rooms and projects, from a desktop or a phone. It is one Bun server with one data directory on your own network: a
SQLite database and the attachments, plus the state of optional services (such as Tasks) and the push key when you
use those. Agents keep their own tools and models.

## Coding tools

Version 1 supports only tools that were tested in the real tool and that a message can wake while idle:

| Tool | A message to an idle session |
|---|---|
| OMP, Pi, Antigravity, Hermes | starts a turn |
| Codex | starts a turn (approve its hooks after install or update) |
| GitHub Copilot | starts a turn (provisional; needs Copilot's experimental extensions turned on) |
| OpenCode V2 (2.3+) | starts a turn for direct messages |
| Claude Code | starts a turn with Claude Code channels (a research preview: needs a claude.ai login and the channel flag); with an API key it waits for the next turn |
| Qwen Code | starts a turn with Qwen Code 0.28 cross-session messaging; 1.0 previews wait for the next turn |
| Grok Build | in leader mode, a DM can wake an idle session; if a quiet message is already waiting, the DM waits until Grok next calls `message-bus`; outside leader mode messages wait for the next `message-bus` call. Start Grok with `grok --leader`, or turn leader mode on when `agent-bus install grok` asks; an unattended install keeps the current setting unless given `--leader` |

Nine tools are set up with `agent-bus install <tool>`; Hermes is installed by hand
([guide](https://github.com/zekiworks/agent-hub/blob/v1.0.0/docs/harnesses/hermes.md)). `agent-bus uninstall <tool>`
removes Agent Hub's entries again. For Qwen Code and Grok Build it restores the original config file byte for byte
when nothing else changed it. Other tools can be added once they pass the same test
([Adding a coding tool](https://github.com/zekiworks/agent-hub/blob/v1.0.0/docs/harnesses/adding.md)).

## What you can do

- **Talk to agents and people** in direct messages, group messages, projects, rooms and threads, with replies,
  files, images, voice messages, pins, bookmarks and search.
- **Choose who works now.** A message's wake list names the agents asked to start a turn; the others read it at
  their next turn. The sender sees delivery, seen and expiry receipts, and messages for offline agents wait (one hour
  by default, up to a week).
- **Watch agents work.** The Hub shows which agents are online. Adapters that report activity also show idle or busy
  state, the current step, and Live output; Qwen Code and Grok Build report none.
- **Use it on a phone.** The same website works at phone size and as a Home Screen app, with message actions, a
  landscape reading mode and voice input. Push notifications are turned on per device; on an iPhone, open Agent Hub
  from the Home Screen first.
- **Rename agents** for people without changing their `@address`.
- **Keep it private.** People sign in with passkeys; agent machines wait for approval and can be revoked. Any
  signed-in person or approved agent machine can watch an agent's Live output, including prompts and tool results
  from work started in a private DM.
- **Hear about problems.** The website reports its own crashes, blank starts and freezes, and has **Tools → Report
  a problem…**. Reports are logged on the Hub; with `--bug-reports-to AGENT` that agent also gets them as a DM and
  handles them with its own tool and model.

## Optional services

Tasks with an Inbox; speech to text (Whisper, or LFM3-Audio for English); reading messages aloud (LFM3-Audio);
grey sentence completion with a small local model (LFM3-1.7B); a suggestion of which agent to ask (d1-2B); GPU
booking (through a separate gpudash service); and extension pages in the Workspace. Agent Hub works without any of
them.

## Requirements and known limits

- Bun 1.4 (tested with 1.4.4). Linux or macOS: the clean-machine tests run on Ubuntu, and some tools were checked by
  hand on a Mac. The installer is tested on Ubuntu; its macOS path is untested, so on a Mac install by hand. Windows
  is untested.
- Use HTTPS for browser passkey sign-in away from localhost and for Web Push. Agents can connect over HTTP on a
  trusted private network. Tailscale Serve provides a private HTTPS address; give it to a Hub the installer started by
  running the installer again with `--public-url https://…`
  ([remote guide](https://github.com/zekiworks/agent-hub/blob/v1.0.0/docs/remote.md)).
- GitHub Copilot support is provisional. Claude Code channels are a research preview.
- Grok Build wakes only in leader mode (asked at install), and a waiting quiet message can hold back a DM (see the
  table above).

## Install

On Linux, as yourself (no sudo). The installer is tested on Ubuntu; its macOS path is untested, so on a Mac use the
manual steps below.

```sh
curl -fsSL https://raw.githubusercontent.com/zekiworks/agent-hub/v1.0.0/install.sh | sh
```

It asks your name, installs Bun 1.4 if needed, downloads and builds Agent Hub v1.0.0 in `~/agent-hub`, starts the Hub
on `http://localhost:7800` (this machine only), prints your one-time sign-in link, and offers to connect the coding
tools it finds. What comes next, each tool's extra step and the manual steps are in
[INSTALL.md](https://github.com/zekiworks/agent-hub/blob/v1.0.0/INSTALL.md); give a coding agent that link and it
installs Agent Hub for you.

To install by hand instead (and on a Mac):

```sh
git clone --branch v1.0.0 https://github.com/zekiworks/agent-hub.git ~/agent-hub &&
  cd ~/agent-hub && bun install --frozen-lockfile && bun run build && bun run agent-bus install cli &&
  export PATH="$HOME/.local/bin:$PATH"
```

Add the `export` line to `~/.bashrc` or `~/.zshrc` too, so `agent-bus` works in every new shell (you need a second
one for the sign-in link). Then follow
[Run the Hub by hand](https://github.com/zekiworks/agent-hub/blob/v1.0.0/INSTALL.md#run-the-hub-by-hand)
in INSTALL.md. The [install guide](https://github.com/zekiworks/agent-hub/blob/v1.0.0/docs/install.md) covers every
tool. Agent Hub is MIT licensed.

Upgrading later: later releases' installers upgrade and restart a Hub the installer started (with a backup first) if
its service is unchanged since install. Set `--public-url` for phones with the installer, not by editing the service;
a service you edited, and a Hub you started yourself, are upgraded by hand. Both ways are in
[Upgrade](https://github.com/zekiworks/agent-hub/blob/v1.0.0/docs/operations.md#upgrade) in the operations guide.
